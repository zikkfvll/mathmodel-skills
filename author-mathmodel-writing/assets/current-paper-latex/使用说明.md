# 当前个人论文结构与LaTeX格式模板

这是从本项目最终合稿提取的个人模板，供以后先沿用当前结构与格式。它不是某赛事官方模板，也不是可直接提交的成稿。所有说明文字、符号、公式、表格和图框仅演示版式，需替换为真实研究内容。

## 怎么用

1. 复制整个目录到新项目，不覆盖已有论文。
2. 在 config.tex 修改题名、队号、赛道或题号、关键词，以及文后声明和附录开关。
3. 在 sections/questions.tex 增减本问文件；默认为四问，摘要、问题提出和问题分析同步调整。
4. 正文逐节替换模板说明；main.tex 只负责顺序，personal-style.tex 集中管理版式。
5. 用 XeLaTeX 编译至少两遍，或运行 Tectonic。编译后核查目录、引用、字体、图片与最终页面；模板能编译不代表研究或赛事格式已验收。

```sh
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
```

也可使用：

```sh
tectonic main.tex
```

编译器应已能使用 cumcmthesis.cls 所需宏包。macOS沿用原稿Songti/Heiti，其他系统回退Fandol；不随模板打包个人系统字体。无需旧项目数据、图片、源码或绝对路径。只写Markdown的任务不因此启动LaTeX。

## 当前继承的格式

- A4，四边25 mm；正文大小继承原class的12.05 pt，行距倍率1.28，首行缩进2 em。
- 中文正文宋体，标题黑体；一级标题居中14 pt，二级14 pt，三级11 pt；题名16 pt，摘要标题14 pt。
- 摘要按逐问一段，关键方法可加粗；目录单独页面，正文重新从阿拉伯页码1开始。
- 一级中文序号，二级“节号.小节号”；每问按“模型的准备—模型的建立—模型的求解与分析”。
- 图表按“问号-序号”，总路线图延续原稿并入第一问图序；符号说明表单独计数，附录图表用A前缀；公式连续编号。
- 保留三线表、图注、正文引用、模型评价/改进/推广、参考文献、可选文后声明和附录位置。

题名行沿用原稿字号，短题名保留原单行下划线；过长题名自动换行，并在题名区域下方加横线。外层由tabular调整为tabularx，以避免新比赛长题名横向溢出。

没有继承原稿的研究内容、队号、研究数字、具体图件、AI使用历史或按页修正。现在不增加不同赛事布局，也不强化作图；图框只是排版位置。以后按当届官方要求决定匿名、封面、目录、页数与声明，不把旧赛要求固定化。

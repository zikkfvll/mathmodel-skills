# 论文低级错误辅助检查

用于用户指定稿件的机械遗漏检查。它帮助定位问题，不改论文、不重算模型、不代表论文验收。整稿语言、实际数字与公式、引用内容、编译和页面检查继续按本轮要求完成。

## 使用

最低要求Python 3.9（使用相应标准库API），本轮实际运行环境为Python 3.12。低于3.9时CLI会给版本提示并退出2；没有据此声称已在所有3.9+版本或所有平台实测。优先使用项目已有的解释器，不为运行检查器改系统Python。

在技能实际目录找到 `scripts/check_paper.py`，使用当前项目的Python环境：

```text
python check_paper.py /项目/论文/paper.md
python check_paper.py /项目/论文/main.tex --root /项目 --json /项目/审核/低级检查.json
```

只检查明确指定的一个Markdown或TeX入口，不遍历整个比赛项目。TeX会跟随该稿件明确的 `input`、`include` 文字依赖。默认允许读取范围为入口所在目录；确有父目录中的共用文字或图件时，显式传入恰好所需的 `--root`。解析后的路径或符号链接若越出该范围，就保持待核，不读取目标。

默认只读稿件，只有指定 `--json` 时才写该报告。报告目标必须与稿件、已读取依赖及正文引用/链接的目标分开；符号链接和硬链接造成的输入别名也不能覆盖。

默认只创建新的报告文件，目标已存在时退出2并保留原字节。确需更新本工具先前生成、带v1工具标识的报告时，加 `--overwrite-report`；它仍不能覆盖任何输入/依赖目标，也不能覆盖普通参数JSON或其他未识别文件。旧版未带此标识的报告请换一个新报告名，不借此参数强行覆盖。检查器不会自动修复、联网、调用编译器或安装依赖。

```text
python check_paper.py /项目/论文/main.tex --json /项目/审核/低级检查.json --overwrite-report
```

模板样张允许有待填说明，使用：

```text
python check_paper.py /模板/main.tex --root /模板 --allow-template-markers
```

该模式仅允许占位说明，不跳过坏路径或未定义的引用。正式成稿不使用模板模式；也不能把模板样张称为可提交论文。

普通模式发现命令定义中的待填词时，会列为 `macro-placeholder` 待核：工具不展开宏，需确认它是否进入正文，并补齐实际使用的配置。例如队号定义为“待填”时，不会因定义体被排除而默默略过；也不会在未确定宏被使用时直接判作正文错误。模板模式允许这类配置占位。

## 目前会检查什么

- 正文中的明确待填词、TODO等占位符；代码块、注释和源码章节不作为正文扫描。源码章节到后续同级或更高层级标题结束，后续数学附录等正常内容恢复扫描。疑似内部工作流路径以提醒报告，需结合语境判断。
- Markdown常用本地行内链接（含平衡括号文件名）、角括号包裹的含空格路径、显式引用式链接、HTML图片目标是否存在；引用标签按空白折叠比较。远程网址只标“未联网核查”；本地“文件#小节”链接只核文件存在，片段内容和同页标题锚点不在检查范围。快捷式引用和HTML的a标签暂不覆盖。
- TeX常用字面 `input`、`include`、`includegraphics`，支持可省略扩展名、静态 `graphicspath`、图扩展名声明及平衡花括号/可选参数。按普通LaTeX入口工作目录解析，不自行猜测import宏的目录行为。
- 直接声明的 `label`、`bibitem`、常用BibTeX条目，与字面的 `ref`、`eqref`、`pageref`、`autoref`、`cref` 和 `cite` 等对应关系；报告可确定的重复键和缺失声明。
- 区分常规列表的缩进续段与真正缩进代码，跳过Markdown围栏和代码、TeX注释、常见verbatim/listing/minted代码环境及行内verb；不会因合法代码中的示例路径要求补图。TeX的普通命令定义和def体不展开；其中含结构命令时只列待核，不把它当作已经执行的文件读取。

- 字面的TeX循环输入列错误；重复输入会重新检查其中标签，避免按文件去重掩盖重复声明。没有标签冲突的合法重复片段不因此被强行判错。

发现目标文件存在，只代表路径存在，不代表内容正确、图可正常显示或输入数据可信。

## 结果怎样理解

|退出码|含义|后续处理|
|---|---|---|
|0|本次静态范围内未检测到错误，可能有语境提醒|仍完成本轮必要的内容、编译和视觉核对|
|1|发现占位符、缺文件、未定义字面引用或重复键等错误|根据具体位置修复，再核受影响范围|
|2|版本不支持、入口/读取失败，或报告路径碰撞/目标已有等导致工具未完成|不能当作检查通过，先解决版本或路径；仅更新本工具已识别旧报告时可明确加覆盖参数|
|3|没有已检测错误，但存在动态路径、远程链接等待核项|按列出的具体范围补人工或适用工具核查|

每条结果带文件、行号、类型和说明。`no_detected_errors`只描述这个工具没有发现所列低级问题，不是整稿PASS。

## 边界

这是轻量静态辅助工具，不是完整Markdown/TeX解释器。不会展开宏、类或包，不理解全部导入机制、条件分支、自定义引用命令或复杂BibLaTeX语法。检测到动态结构时列为待核；未识别的自定义语法仍可能漏检，编译日志和人工核查不可省略。为避免读取任意大文件，文字依赖设有128次TeX输入展开和单文件2MB的上限，超出部分单独核查。

不会做“某个数字在正文出现就算核对通过”的扫描，也不验证论文真实性、数学正确性、参考文献真实性、全部语言或PDF布局。不把缺工具、脚本无报错或文件存在当作相关验收已完成。

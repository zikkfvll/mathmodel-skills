# 案例：2026 MathorCup B 赛道论文

此案例展示如何把四问的条件模型、实际结果和适用范围整合成一篇连续论文。完整材料见 [MathorCup 比赛目录](https://github.com/zikkfvll/mathmodel-learning/tree/main/competitions/2026-mathorcup-b)，包括论文、LaTeX 工程、Q1—Q4 程序、必要输入和结果。

借鉴本案例时，重点看问题之间如何衔接、公式如何解释、结果如何进入论证。原比赛的参数、阈值、工具使用日期和格式要求不能直接用于新比赛。

## 四问怎样连起来

| 问题 | 研究内容 | 写作中需要区分的结论 |
|---|---|---|
| Q1 | 气象等环境特征的异常分析与排序，纳入 ERA5 格点降水 | 关注特征与已证致灾原因；异常排序与后问物理参数 |
| Q2 | 局部饱和细粒材料的剪胀、排水与孔压支承条件 | 局部临界状态与整股泥石流首次形成；设计参数与当地实测值 |
| Q3 | 局部首达时间分布、条件预警和敏感性 | 模型内首达与自然触发时刻；模拟包含率与真实事件覆盖率 |
| Q4 | 规定入口后的传播仿真与多保真 GP 辅助判断 | 条件传播结果与完整自然灾害链预测；代理预估与物理计算核定 |

跨问关系通过明确输入和条件衔接。Q1排序不直接变成Q2的物理权重，Q2/Q3的局部首达也不自动提供已验证的Q4整股入口。论文用相应条件说明这些连接，保留未达到、窗末运动和负行动余量等影响解释的结果。

## 论文组织

| 部分 | 组织方式 |
|---|---|
| 题名、摘要、关键词 | 题名覆盖四问；摘要先总领，再逐问说明方法和实际答案 |
| 问题重述 | 简要背景与问题提出，保留作者已经确认的表达 |
| 问题分析 | 从目标与数据引出各问的方法职责和整体路线 |
| 模型假设与符号说明 | 保留真正进入模型的假设；符号给出含义与单位 |
| 模型建立与求解 | 按问组织“模型准备—模型建立—求解与分析”，连接公式、计算和结果 |
| 模型评价、改进与推广 | 集中讨论优点、限制与适用范围，避免重复逐问答案 |
| 文献、声明、附录 | 按比赛要求安排引用与工具披露，源码附录保留实际采用程序 |

最终论文非源码附录部分为30页，源码附录283页，总计313页。页数来自该案例的内容与提交安排，不是其他比赛的模板目标。

## 从案例中学习写法

- **先说研究对象。** 在给局部材料状态方程前，解释为什么讨论冰岩体撞击后的湿细粒材料，以及模型能回答哪一种临界问题。
- **解释参数身份。** 将读点、外部实验、设计参数与当地实测分开交代，再说明它们怎样进入模型。
- **连接公式与结果。** 累计剪切等解析关系用于解释数值规律；近边界近似误差同时写明适用条件。
- **保留真正的反例和不利结果。** 未达、误报、代理误差和负行动余量都用于限定判断范围，不通过措辞变成成功结果。
- **把运行记录放在合适位置。** 正文聚焦对象、方法、结果与证据；文件指纹、运行回执和详细软件命令由工程说明承载。

写作时从比赛目录中对应的正式结果表取数，不从此案例摘要转录完整计算结果。

## 版式与复用

论文沿用项目使用的 CUMCMThesis 类文件，并调整为个人版式：A4、约25 mm页边距、宋体正文、黑体标题、三线表、公式连续编号、分问图表编号。它是第三方模板基础上的个人格式，不能标为 MathorCup 官方模板。

可复用的空白结构见 [个人 LaTeX 模板](current-latex-template.md)，科学正文、旧图、队伍信息和历史工具记录均不进入模板。新比赛应重新核对匿名、封面、页数、引用与 AI 说明等要求。

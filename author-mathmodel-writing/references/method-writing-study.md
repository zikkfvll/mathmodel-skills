# 按实际方法学习论文写作

用于某一问或某个已采用方法的成稿、改写和写法学习。研究方案与结果保持已确认版本；学习其他论文的表达不自动授权更换模型、增加实验或重算。

需要新检索参考或获取原文时，按同包[学校电子图书馆接入](../../personal-mathmodel-modeling/references/institutional-library.md)复用学校资源，未知时首次询问学校名称或入口；已有原文的局部修改不重新询问，也不重启检索。

## 先按方法和论证任务找段落

先确认本问实际用了什么方法、承担什么任务、怎样实现、得到什么结果，再定向匹配参考。按方法名称及同义词检索，并继续核模型职责、数据形态和验证是否相近；论文题目或领域相同，不等于表达段落适合本题。

写作优先学习近三年国赛一等奖的同方法对应小问。例如采用层次分析法时，重点看它如何说明选择该法的理由、组织层次和指标、解释判断矩阵及比较依据、引入权重求解与一致性检验、衔接结果和应用。参考稿有某个步骤不代表本题已经做过；本题没做的一致性或敏感性检查不能靠文字补成已完成。

需要更深入的机制、方法或实验表达时，补充合格SCI、Nature系列或CCF-A原文；研赛一二等奖、美赛O/F也可提供相同任务的写作参照。所有材料按入口的最新年限与资格要求核验，不因为写作模仿而放宽筛选。

## 复用本问实际学习池

每问以合计20篇合格、去重且实际读到相关原文的论文为期望目标，可根据相关性、获取条件和时间调整，沿用研究设计阶段的共同记录。六线分别检索、合计计数；一篇跨线出现只计一次，同一篇多个段落也只计一篇。

写作从该池中优先取实际方法的段落，再按需要补新的合格参照。不是每个方法再找20篇，不要求每次局部润色或重排版都重新读20篇。只有标题、摘要、下载记录或未核资格的候选不算已完成学习；实际篇数与调整理由如实标明；缺关键原文才定向补检索与获取路径，不因不足20篇阻断写作，不造阅读成绩。

## 具体学什么

对相关段落细读并作少量对照，既观察共同结构，也观察不同作者怎样写同一方法：

| 写作位置 | 学习重点 |
| --- | --- |
| 问题分析和方法引出 | 如何由本问困难、数据或约束自然引出方法，怎样说明选择理由 |
| 模型建立 | 专业术语、对象与符号定义、公式顺序、公式前的用途说明和公式后的含义解释 |
| 求解过程 | 怎样交代具体算法、参数和实施步骤，并区分数学模型、求解算法与软件工具 |
| 结果与分析 | 先回答什么、怎样引图表、怎样由数字解释主要关系，怎样交代比较条件与适用范围 |
| 段落和句式 | 句子长短、术语密度、转折衔接、总分结构及论述节奏，避免机械套连接词 |

学习卡放在现有本问资料索引或写作记录中即可：来源与奖级证据、页码/小节、对应方法和段落功能、值得学的表达特点、本题怎样使用。必要时保留短摘或定位，不大段抄存论文，也不另外建设庞大语料库。

## 复用和积累真实写法案例

先按[案例索引](writing-examples/index.md)找与本问方法职责和写作位置相近的已读原文实例；可借论证顺序与解释方式，不能因案例存在就选用其模型。需要新例时按[案例积累方式](writing-example-collection.md)完成来源、资格、原文定位、段落功能和本题事实的对照。每次只补本问用得上的片段，不为丰富库重复阅读整包附件或强制新增篇数。

## 从学习到本题表达

先用自己的话归纳参考段落在做什么，再写本题的事实与逻辑，最后检查表达是否达到参考稿的专业程度和流畅度。可以充分学习用语习惯、句式组织、公式解释和段落节奏；通用数学术语与标准公式准确使用，需要时引原始方法来源。

不要把参考原句逐句替换名词拼成新文，不移植它的数值、指标、样本量或效果。不同参考之间的结构冲突应按本题论证与作者风格选择，不能各取一句拼成不连贯段落。亲改正文与旧稿文风仍优先，参考是提升表达的材料。

起稿后从首次读者视角复读：是否讲清本问对象、方法选择、公式用途、实际求解、结果和答案；每条专业判断是否有本题证据。整稿语言轮沿用全文逐字要求；用户明确局部任务时核指定范围和受影响一致性，不把局部检查写成整稿新通过，详见[验收范围](layout-and-qa.md)。科学内容疑点交结果负责人，不在写作轮次擅自改结果。

## 摘要与截止时间

模型和结果陆续就绪时及时补齐摘要与全篇骨架，不为了等待全部文献或照搬“摘要最后写”而把交付拖到最后。最终再据各问确切结果统一摘要、题名、关键词和主结论；未完成的内容按当前授权范围如实处理。

# 详细写作规则

用于起草、压缩、润色及语言审核。局部任务执行相关部分，不为套流程添加审批。

## 作者原文与材料定位

核清：亲改原文是什么、当前工程是哪一版、旧论文是哪篇、确认结果在哪里、哪些只是候选方法。用户说“前面已经改过”时，回读真实原文，不能继续凭旧摘要重写。

对亲改段落记录实际的保留、必要纠错、压缩、移动或删除，提供原改句或可读差异。没有问题的部分不制造修改。用户明确逐字保留的片段保持字句；事实与题面冲突时指出具体依据，不能以保留原文延续错误。

先学问题重述、对象选择、模型引出、公式前后解释、步骤与结果衔接、句式、段长和节奏。旧论文自身的措辞错误或过强结论不是仿写目标。旧风格说明中与后续要求冲突的段落不得照搬。

## 让首次阅读者能复述研究

读完每问，应能回答：

- 研究对象、空间范围及选择理由是什么？
- 哪些是观测、文献参数、设计情景或模型假设？
- 输入的单位、可用时间和支持区间是什么？
- 模型建立什么关系，符号各指什么？
- 如何由输入算到输出，主要数值步骤是什么？
- 答案是什么，对什么条件、尺度和比较对象成立？

出现阅读断点时补最少必要信息，不靠堆缩写或增加形容词。保留统计名称和专业术语，首次准确解释。内部代号、区段标签、文件名和状态码不能替代叙述。

## 公式与定量表述

先说明关系与用途，再给必要公式，随即解释新增符号、单位、下标和适用条件。不要连续堆出没有对象说明的公式，也不为口语化删除关键推导。

重点检查：

- 高度差和层差明确谁减谁；代理量不改名为更强的物理量。
- 时间原点、相对时刻、绝对钟点、截止时刻、窗口与事件阶段不混用。
- 置信区间、预测区间、历史分位、数值括区和背景带分别命名。
- 有限时间区间不包含“窗内未达”离散类别；预测集合含两者时分别说清。
- 异常、相关、联合变化、预测和因果贡献不混称；样本数、分母及支持条件明确。
- 百分比与百分点、峰值与均值、累计量与变化率、末时状态与窗内曾达到的覆盖分别解释。
- 标准化响应误差、原单位误差、分类表现和边界定位分开评价，不由一个指标宣称全面最优。

精度与原结果、解释需要一致，同列小数位统一，保留有意义的正负号。正文解释图表，不逐行朗读表格。

## 段落、词汇与密度

一段承担一个主要论证任务。主题之后各句应构成定义、证据、因果、比较或解释关系；不要依靠“首先、其次、此外、综上”串联松散句。

使用领域中真实存在的名称。模型组合名应能由实际方程或流程解释，不为显得高级发明复合词。同一术语保持一致，不为避免重复随意换名。

“优化”要交代优化对象、准则或具体改进机制。没有量化证据时，可以准确说明校准了何种影响、如何分配计算或构造集合，不能宣称未测出的精度提升、加速倍数或普遍稳健。“首次、显著、高精度、全面优越”等判断需要相应证据；证据不足时调整措辞，不在写作轮次擅自重算。

重点加粗用于模型名称、核心方法、关键答案及作者指定标签；不整段加粗。关键词覆盖主要任务和核心模型，不罗列全部统计量，不把某次被删除的关键词永久列为禁词。

## 防御性写作的最小处理

| 问题 | 处理 |
| --- | --- |
| “但这只是……”反复否定本段价值 | 删自我评价，保留已成立的对象与条件 |
| 未采用变量、资料缺口占主线 | 移出主文；实际输入与假设在相应处说清 |
| “未通过／待核验”描述运行或放行状态 | 改为正面流程；实际无效状态不能改成成功结果 |
| 每段重复“不代表因果／不能证明” | 先准确命名研究对象，在必要位置集中界定一次 |
| “效果有限、严重不足”等笼统评价 | 在模型缺点中写清条件与影响，与改进逐项对应 |
| 结果本身是未达、误报、负余量 | 保留事实，中性陈述对象与条件，不能反转结论 |

不足集中在缺点与改进，不取消方法定义、样本条件和核心证据。主文用正面设定交代必要信息，不额外堆免责声明。

## 学习其他论文

按问题和实际方法选择相关论文，观察方法如何引出、公式如何解释、结果先说什么、数据怎样支撑贡献。需要定向学习表达时读 [按方法学习论文写作](method-writing-study.md)。例如本问用了层次分析法，就找合格国赛一等奖论文中层次分析法对应的小问与段落，认真学习其语言、术语和论述推进，再按本题对象、判断依据和真实结果成稿。

多篇对照能帮助识别通用专业表达和各作者的具体写法。作者指定Nature系列、CCF-A或数模高奖稿时，按入口最新年限、分区、奖级和相关性筛选，并沿用可调整的每问学习目标，核实相关性、来源与身份；已有合格阅读记录直接复用。

学习论证功能和术语，不复制独特句子、成绩或构图，不把获奖身份当数学正确性的证明。引用原论文自己的数据或结论，不用二手解读冒充原始证据，不把检索过程写成论文故事。

可按任务配合已有科研写作、润色、LaTeX/PDF或引用核验技能。有 `nature-writing`、`nature-polishing`、`5writing`、`6verity` 等时，只读相关指导；它们不覆盖作者风格、既有工程或当届要求。缺这些辅助技能不阻止普通编辑。

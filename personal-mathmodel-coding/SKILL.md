# 逐问编程、计算与图表

用于路线已确定后的执行。先读本问的方案、输入索引、相关前问接口和最新审核反馈，只读取本次真正需要的数据；复用有效的清理成果、计算结果和论文学习记录。核心模型或数据口径未定时，将具体疑点交回设计讨论。

## 实现方式

- 每问默认交付一至两个 Python 程序，通常为分析入口和绘图入口；这是提交代码的偏好，不限制整场比赛文件总数。必要的配置、输入、结果和开发辅助材料另存，不为凑文件数压成难读的长函数。
- 保持普通脚本即可，不另建复杂工程框架。参数、字段映射和随机种子集中管理，命令行支持输入目录、输出目录和需要的随机种子；避免个人电脑绝对路径、私人模块、临时 Notebook 和交互会话依赖。
- 保留必要中文注释，解释输入、公式、统计口径及边界处理。计算结果来自程序实际运行，不把预期数值硬编码成输出。
- 每张图对应清晰函数，字体、字号、尺寸、颜色、线型、图例及导出格式集中设置；绘图读取正式结果，不另算排序、重新拟合或悄悄改结果。支持单独重绘，按论文需要输出高清位图和适用矢量图。
- 按任务需要使用可用的编程或绘图技能，例如 `3coding-visual`、`nature-figure` 及具体方法技能；只借用本问需要的能力，不继承额外框架、固定图数或自动串联流程。

## 运行与复用

先确认本轮可写范围、输入版本、公式与单位、需要的结果、预算及验证重点。首次执行、换环境或工具报错时，按[任务环境检查](../personal-mathmodel/references/task-environment.md)只核本轮所需解释器、已声明依赖和相关工具；相同任务与环境已有可用证据时复用，不每次重查全套。用户已确认路线后，自主完成路径、变量名、普通搜索、绘图和代码修复等细节；需要改变核心方案、证据含义或预算时再讨论。

复用旧脚本、导出器或批处理前，核其真实写入根与解析后的输出目标（含相对路径、默认值及链接目标），确认不会写入原稿或保护目录。先在获准的新输出目录运行；必要时保留可恢复的小稿件副本。不能确认写入目标时先修新副本中的路径，不带风险试跑，也不为备份复制全部大数据。结束核必要差异；误覆盖如实保留范围与恢复状态，未恢复不能写保护通过。

提供公开依赖清单和明确的分析、绘图命令，并实际运行适用入口。沿用项目指定环境，不改系统环境。运行记录保持简洁，能追到实际输入、代码、配置、种子、环境和输出；启动成功、退出码或文件存在本身不代表结果正确。

从确认清理数据开始的分析复现，与从原始附件重建清理数据的完整复现要分清。说明必要缓存和生成途径；输入、代码及口径未变时复用可靠成果，新增分析仅运行受影响部分，不重读整套附件或重复求解。

高影响缓存或既有审核的复用，沿用[共享资料中的复用记录](../personal-mathmodel/references/shared-context.md)：标明真实依赖、继承检查范围与容差、仍有效或已过期的依据。接口错误按实际失败路径核查，不能只测正常返回；已核且未变的物理结果不因接口补丁重跑。

缺失值不自动填零或插补，极端值不自动删除；元数据未知时只暂停依赖该定义的部分。结果或接口有变，明确通知依赖它的图表、文字和下游问，并保留可识别的旧版本。

## 核对、返修与交付

选择能判断本问结果是否可信的必要核对：如输入与单位、约束与边界、简单可核算例、敏感性、稳定性或与使用场景一致的验证。按模型需要执行，不机械套齐所有检查，也不为增加断言数编写重复测试。

执行者完成自检并报告实际证据；核心结果由审核方独立核查。审核意见交执行方具体修复，返修后核对受影响结果及其图文，不批准自己的核心结果。未运行或未覆盖的事项准确标明，不写作已通过。

交付与当前任务范围相符的材料：源码、公开依赖与命令、必需输入和说明、同一正式版本的结果表、可独立重绘的论文图、连续 Markdown 正文所需的结果说明、简洁核对记录及完整包。正文由写作方负责时交出可直接使用的表图与解释，不再另写冲突版本。

交付说明对应本问要求、实际输出与未达项，不用自检通过替代完整答题。下游要换用结果或入口时，按[交接采用规则](../personal-mathmodel/references/collaboration.md)核接收与实际采用，保留仍待同步的项。

达到已定目标、必要核对完成且已知实质问题闭环后收口。优先修正真实错误；增强规模服从剩余时间和收益，不反复全面审计，不因还能加模型、图或测试就继续扩展。文献学习由建模与写作阶段共用，每问实际论文学习记录不在编程阶段重做。

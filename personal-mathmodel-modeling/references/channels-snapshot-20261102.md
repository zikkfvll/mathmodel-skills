# 文献渠道使用记录（2026年11月2日）

本页提供一次公开检索与全文获取的路径记录，供选择渠道时参考。渠道、机构订阅和期刊资格会变化，检索新问题时应重新核实。参考论文的相关段落分析见 [写作案例](../../author-mathmodel-writing/references/writing-examples/index.md)。

## 已验证的获取路径

| 渠道 | 记录中的实际结果 | 使用时还需核对 |
|---|---|---|
| Crossref、OpenAlex | 公开 HTTPS 查询与日期过滤取得有效元信息 | 与具体小问的相关性、正式版本、分区或奖项 |
| Nature、SCI开放全文 | 取得可解析的正文PDF | 中科院分区与SCI/SCIE身份；不能只凭期刊品牌入选 |
| CCF-A会议 | 取得ICML/PMLR正文 | 当前目录、主会论文身份与方法适用性 |
| 国赛 | 取得2024A题作者公开稿，并用高校获奖记录交叉定位 | 作者、题名、年份和奖级是否指向同一稿件 |
| 研赛 | 取得候选正文与正式奖单 | 匿名稿与获奖队伍的身份绑定；作者自述不单独充当奖级证据 |
| 美赛 | 取得两份正文；其中2024A题2405424稿首页队号与COMAP Outstanding记录对应 | 稿件身份、题号及官方O/F记录；文件名不能替代核验 |
| GitHub全文回退 | 公开仓库直链超时时，官方Contents接口原始响应成功取文件 | 权限、完整传输和实际PDF内容 |
| Web of Science | 通用入口可打开至现代检索页面 | 学校认证与付费全文权限需要实际登录验证 |

这次获取记录共包含7份主论文。文件检查核了PDF签名、非零页数和题名或DOI；文件可读不等于已完成方法精读，也不表示它适合任何未来小问。正文内自带附录与另外下载补充材料是两种情况。

## 获取中遇到的问题

- 队号命名的美赛文件可能是证书，题号命名的PDF也可能只是题面。打开正文并核对身份后再保存为论文。
- 中文文本抽取可能乱码，PDF渲染也可能缺字。应换可用渲染方式核读，不从坏提取中猜测原句。
- 有全文但分区未核、或有奖单但稿件身份未绑定时，分别保存获取和资格状态；完成身份核查后再进入合格参考集合。
- 通用WoS入口只提供检索入口，不代表已拥有学校订阅。各问复用使用者提供的学校资源与合法访问方式。

## 中科院分区来源

记录时核到中国科学院文献情报中心2026年3月27日的 [期刊分区表声明](https://las.cas.cn/news/tzgg/202603/t20260327_8178738.html)，其中说明自2026年起不再更新发布期刊分区表，其他机构表与其无关。

实际筛选应核后续维护状态，记录所用版本、期刊大类与小类及其合法来源，不凭当前年份生成“最新CAS”标签。不同口径会改变是否入选时，与使用者确定取舍。

# 共享资料与恢复

优先复用已完成的资料盘点、清理和来源说明。指定负责人统一维护公共口径，各问提出需求，避免静默各改一份输入。

常驻信息可放现有文件，不要求固定文件名或数据库：
- 全局简报：每问对象与阶段、当前有效成果、共同决定、跨问依赖和下一步。
- 资料索引：来源、位置、格式、字段与单位、时间空间含义、质量规则、处理状态、必要来源定位。
- 学校资源条目并入资料索引：学校与公开电子图书馆/校外访问入口、相关数据库、实际验证状态或用户暂不提供的选择；各问及写作复用，不保存凭据，也不把旧会话登录状态自动继承为当前可用。首次文献任务的信息询问遵[学校接入规则](../../personal-mathmodel-modeling/references/institutional-library.md)。
- 本问卡：研究审核/执行对话ID、当前方案、用户已确认决定、实际结果、未解项、输入输出接口及确切来源版本。

新对话先读上述相关条目，再定向读取。大表和栅格由程序读必要字段、行窗和区域；聊天接收需要的摘要、样例或图。节省重复解释、处理和上下文装载，不假装实际计算无需读取输入。

每问完成后，总控依据本问已确认答案与你梳理对下一问的影响，再交由下一问研究审核与你设计具体做法。后问继承前问有关的定义、参数、表或函数入口，同时了解单位、支持范围和未被验证的解释。前问算法、排序或分数不自动转成后问物理参数；局部首达、整股形成、释放与下游到达等对象须分清。

摘要提供定位与可复用理解，关键公式、含义或结果受到质疑时回查对应原文与数据片段。独立复核者读取必要原始证据，不能只接受执行者总结。

公共数据含义、处理规则、正式结果或接口变更时，保留旧版，记录变化并通知相关组；只使受影响图文、审阅及接受记录过期。沿用已有版本记录；普通讨论不重新哈希全附件。冻结与最终复现时才补齐实际输入、代码、配置、环境和输出绑定。

关键复用在现有交接卡简记：实际继承的输入/配置/代码与必要环境身份，旧证据检查过什么及适用容差，本轮哪些依赖没变、哪些已变而需重查。身份应涵盖真正读取的间接输入，不能只绑定入口文件。标识优先沿用已有版本或回执，正式冻结再补必要指纹；不为普通讨论重复全量哈希或复制大数据。仅样式变化通常不使科学结果过期，输入或科学定义变化则重查实际受影响链。

跨工具无法访问本地目录时提供轻量交接包，不能声称读过未提供的文件。用户无需反复上传全量附件，必要原文再定点补交。
